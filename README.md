# AdminConsole

## Overview
AdminConsole is a web application designed to streamline various employee management tasks such as employee database management, attendance tracking, payroll calculation, and more. The application provides different levels of access for both administrators and employees.

## Implemented Features

| Feature                   | Description                                             |
|---------------------------|---------------------------------------------------------|
| Employee Database         | Manage employee information, including ID, name, and salary. |
| Attendance Tracking       | Track employee attendance records.                      |
| Payroll Calculation      | Calculate employee payroll based on attendance and salary. |
| User Authentication      | Differentiate between administrators and employees and provide appropriate access levels. |

## Planned Features

| Feature                   | Description                                             |
|---------------------------|---------------------------------------------------------|
| Admin Dashboard           | Provide administrators with a dashboard for managing employees and accessing reports. |
| Employee Self-Service    | Allow employees to view their attendance records, submit leave requests, and update personal information. |
| Reporting                | Generate various reports such as attendance summaries, payroll reports, and employee performance metrics. |
| Notification System      | Send automated notifications to employees for important updates, reminders, and announcements. |
| Mobile Access            | Develop a mobile-friendly version of the application for easy access on smartphones and tablets. |

## Technologies Used
- Java
- Apache Tomcat
- MySQL
- HTML/CSS
- JavaScript

## Setup
1. Clone the repository.
2. Set up the database schema using the provided SQL scripts.
3. Configure the database connection in the application properties file.
4. Build and deploy the application to Apache Tomcat.
